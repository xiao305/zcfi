使用 GitHub Personal Access Token 登录

Token 怎么获取？需要什么权限？
  • 打开 GitHub Token 设置，新建 Token；
  • 基础功能勾选 gist（必填）；
  • 需要自动生成博客页面时，再勾选 repo（公开仓库用 public_repo 即可）；
  • 支持经典 Token（ghp_…）和细粒度 Token（github_pat_…），后者给 Gists 读写 + 本仓库 Contents 读写权限即可。

Token 只保存在当前标签页的 sessionStorage，关闭标签页即失效；登录一次后切换板块无需重复输入。

验证会用你的 Token 读取本站的 Gist 数据并检查权限，不会上传或转发给任何第三方。
